# 比亚迪授权服务店 —— 原厂车漆信息核实话术（中文）

> **性质**：这是研究用的询问模板，**不是比亚迪官方流程**。比亚迪公开资料中没有说明“服务店能否凭 VIN 查询原厂车漆信息”，因此本话术的目的就是**去验证这件事**。回答可能是“能”“不能”或“只能看到颜色名称”，三种都是有价值的结果，请如实记录。

## 0. 使用前提（必读）

1. **只用你自己车辆的 VIN，或车主书面同意使用的 VIN。** 不要使用他人 VIN，不要在网上公开完整 VIN（见 `batch7/vin_evidence_template.csv`：只保存 VIN 的 SHA-256 哈希和前 9 位）。
2. 服务店有权拒绝提供内部系统信息；请礼貌询问，不要施压，不要要求对方违反规定。
3. 不要拍摄、记录他人的客户信息或店内系统里与你车无关的内容。
4. 只有**书面/屏幕/打印的记录**才可能成为证据；口头回答只能记为“店员口述”，**不能**作为 VERIFIED_OEM。

## 2. 准备资料

- 车型、年款、动力版本（例：海豹 2023款 …）
- 销售合同/发票上的**颜色名称**（例：亚特兰蒂斯灰、雪域白）
- 机动车整车出厂合格证/行驶证上的**车身颜色类别**（只会是 白/灰/黄/粉/红/紫/绿/蓝/棕/黑 之一，见 GB/T 21085-2020）
- 是否做过补漆/钣喷（有无维修记录）
- 一部手机（拍照用）、笔（记录姓名/工号/日期）

## 3. 开场白（电话或到店）

> 您好，我想**核对我这辆车的原厂车漆信息**，用于以后补漆和资料存档。我的车是 [品牌/车型/年款]，合同上的颜色是“[颜色名称]”。请问售后服务店的系统里，能不能按**车架号**查到这辆车的**出厂车身颜色**？

## 3b. 不需要 VIN 的“政策性询问”（可先打 950858 或 400-830-3666 做）

> 我想了解一个一般性问题，**不涉及具体车辆**：比亚迪授权服务店是否可以凭车主的车架号，查询并告知这辆车的**原厂车身颜色/色号**？如果可以，服务店能提供**书面说明或系统截图**吗？需要**车主本人到店**并出示什么证件？不同品牌（王朝/海洋/腾势/仰望/方程豹）是否一样？

记录：接线员/工号、日期、原话、是否给出书面渠道。这一步**无需任何 VIN**，结果能直接回答“这条路线是否存在”。

## 4. 问题清单（按顺序问，记录每一条回答）

**A. 出厂档案（build record）**
1. 系统里能否按车架号调出这辆车的**出厂配置/车辆档案**？
2. 档案里的**车身颜色**显示的是：只有颜色**名称**，还是同时有**颜色代码/色号**？
3. 显示的颜色名称是否与我合同上的名称完全一致？（请对方读出原文）

**B. 色号/涂料字段**
4. 系统里有没有“油漆/涂料/色号/颜色代码/涂装代码”这一类**字段**？字段名叫什么？
5. 这个字段显示的是**原厂色号**，还是**调漆配方号**（例如钣喷系统里的配方编号）？两者是否是同一个编号？
6. 该编号是否有**多个变体**（例如“标准配方”与“偏差色/变体”）？
7. 该色号是否区分**亮光/哑光**？

**C. 书面确认**
8. 能否**拍照**或**截图**该画面（要求画面里同时能看到**车架号**和**颜色/色号**）？
9. 如果不能拍摄，能否**打印**一份？或出具**加盖服务店公章的书面说明**？
10. 如果只能口头告知，能否请对方**写在纸上**并签名/写工号？

**D. 钣喷调漆体系**
11. 比亚迪官网称精诚钣喷使用阿克苏诺贝尔、巴斯夫、东来的修补漆并采用“原厂数据、原厂配方”：**贵店实际使用哪一家**？
12. 调漆时依据的是**原厂色号**，还是**现场分光比色**？有没有留存该车的调漆单/配方单？

**E. 维修历史**
13. 这辆车在贵店系统里有没有**补漆/钣喷**记录？（若曾重喷，现在的车漆可能不等于原厂漆。）

**F. 不能提供时**
14. 请问应该联系**哪个部门**（售后/配件/技术支持/厂家客服）？
15. 请问为什么不能提供（权限、制度、系统没有该字段）？——**这个原因本身就是需要记录的结果。**

## 5. 取证清单（现场逐项勾选）

- [ ] 服务店名称、城市、品牌网络（王朝/海洋/腾势/仰望/方程豹）
- [ ] 回答者的角色（前台/服务顾问/钣喷技师/配件）与日期时间
- [ ] 系统界面或打印件**同时显示** VIN + 颜色名称 + 色号（照片/截图，保存在私人位置）
- [ ] 色号字段的**原文**（逐字抄写，含字母/数字/连字符）
- [ ] 是否亮光/哑光、是否有变体
- [ ] 字段性质：原厂色号 / 配方号 / 不明
- [ ] 是否有补漆/钣喷记录
- [ ] 车上若有色号标签：位置 + 照片（**VIN 铭牌同框**）
- [ ] 对方拒绝或无法提供时的**原因**

## 6. 结果如何记入数据库（`batch8/verification_results.csv`）

| 取得的证据 | 记为 |
|---|---|
| 服务店系统/打印件显示 **VIN + 颜色名称 + 色号**（有照片/截图/盖章说明） | **VERIFIED_OEM**（写明服务店、日期） |
| 车上色号标签照片，**VIN 铭牌同框**，车型年款可识别 | **VERIFIED_LABEL** |
| 只有口头回答 | 保持 POSSIBLE/CONFLICTED，备注“店员口述”，**不得升级** |
| 显示的是调漆配方号 | **PAINT_SYSTEM_REFERENCE**（不是原厂色号） |
| 只显示颜色名称、无色号 | 记为“系统无色号字段”（这是有效结果，帮助判断该路线是否可行） |
| 多个来源报同一色号 | 仍不是 CORROBORATED，除非它们来自**独立的 OEM 级来源** |

## 7. 不要做的事

- 不要用别人的 VIN；不要请求店员提供其他客户资料。
- 不要接受或点击你不理解的法律条款；不要绕过任何付费/账号限制。
- 不要把“重新喷漆后的车”当作原厂色的证据（先问第 13 题）。
- 不要把任何配方（如 BASF Formula Finder 里的配方）复制进研究库（见 `baslac_manual_test_plan.md`）。
