# To an authorised service centre: written confirmation of a vehicle's factory paint code (English; for use by the vehicle owner)

> **A research template, not a BYD-approved procedure.** BYD's public documents do not say whether a service centre can retrieve a factory paint code from a VIN, so the purpose of this request is to **find out whether it can be done**.
>
> **About the VIN:** the lookup genuinely needs the VIN, so it is provided **only if the vehicle owner voluntarily agrees**, and **by the owner in person** to the service centre. The researchers will **not collect, store or publish a full VIN** and will **never use anyone else's VIN**.

## Owner's details (the owner fills these in; do not send them to the researchers)

- ☐ I am the registered owner and make this request voluntarily
- Model / model year / powertrain: ________
- Colour name on the contract / brochure: ________
- Finish: ☐ gloss ☐ matte ☐ not sure
- Touch-up or respray work: ☐ no ☐ yes (describe) ________
- VIN: **show it to the service centre in person; do not write it into anything sent to the researchers**

## The request (can be printed and handed over)

> Hello, I am the owner of this car. Please look up, in your **service / vehicle-record system**, the **factory body-colour information** for my VIN and **confirm in writing**:
>
> 1. What **colour name** does the record show?
> 2. Is there a **factory colour-code / paint-code field**? If so, what is the **exact code**? (please copy letters, digits and hyphens exactly)
> 3. Is that number the **factory colour code**, or a body-shop **mixing-formula / variant number**?
> 4. Is the finish **gloss** or **matte**?
> 5. Does the system show any **respray / bodywork** on this car?
>
> Please give the **written record** in any of these forms: a **screenshot** (VIN, colour name and code visible together), a **printout**, or a **stamped statement**. If it cannot be provided, please **write down the reason** (e.g. policy, the system has no such field, another department holds it) and tell me which department to contact.

## How the answer is used

| Evidence obtained | Recorded as |
|---|---|
| Dealer system / printout / stamped statement shows **VIN + colour name + code** | may be recorded as **VERIFIED_OEM** (that vehicle only; centre and date named) |
| Verbal answer only | **no upgrade**; a lead only |
| The number is a mixing-formula number | **PAINT_SYSTEM_REFERENCE** |
| Colour name only, no code | record "system has no code field" (a valid result) |
| Refusal / inability | record the **reason verbatim**; status unchanged |

Nothing here changes the code for other models or years automatically, and codes are never decided by how many websites repeat them.
